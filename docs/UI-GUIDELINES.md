# OrbitDown 组件规则

组件视觉参考 [RadarUltra Codex 页面](https://radarultra.com/zh/codex)，应用于现有下载管理功能。背景沿用 SVG 轨道和 CSS 渐变；不引入参考页的产品文案、数据或功能。

| 部件 | 规则 |
| --- | --- |
| 文案 | 仅保留功能名称、状态和必要说明，不添加标语、装饰英文或营销文案。 |
| 色彩 | 主文字 `#1d1d1f`，次文字 `#6e6e73`，柔灰控件 `#f5f5f7`，轻边界 `#e5e5ea`；业务状态保留语义颜色与文字。 |
| 面板 | 纯白卡片，桌面28px、手机24px圆角；普通面板无大投影，弹窗和菜单保留必要浮层阴影。 |
| 数字 | 速度和空间数值突出，单位缩小、对齐基线；保留原单位换算与格式。 |
| 导航和按钮 | 浅灰胶囊轨道、白色选中项、轻投影；深色主操作、带轻边界的浅灰次操作，灰底卡片内使用白色次操作；删除使用浅红底。避免将操作按钮呈现为无边界的散落文字。手机主导航五等分，底栏悬浮并保留安全区。 |
| 表单 | 单行输入、搜索和下拉触发器为胶囊；多行输入采用较小圆角。下拉选项至少44px高，保留键盘搜索、方向键及退出行为。 |
| 布局 | 设置最大1360px，其他工作区最大1120px；手机按视口收拢。任务操作使用紧凑非模态菜单。 |
| 操作区 | 分类和标签使用紧凑行，名称、路径在左，操作在右；窄屏按需换行。卡片内操作组不保留额外底部外边距；表单的操作按钮与输入框底边对齐。 |
| 实例连接 | 登录页即连接页：提供 qBittorrent WebUI 地址、用户名、密码并验证登录；凭据仅保存在本机安全存储。登录后的左上角连接状态可重新配置连接；修改输入后清除旧测试结果，密码不回显。 |
| 无障碍 | 保留可访问名称、选中状态、焦点提示、44px触控和手机16px输入；尊重减少动态效果、减少透明度及高对比度偏好。 |

## 动效规范

时长与缓动 token 定义在 `frontend/src/styles/motion.css`：`--motion-fast`(120ms)、`--motion-base`(200ms)、`--motion-slow`(320ms)；`--motion-ease` 为主缓动，`--motion-spring` 带轻微过冲，仅用于小位移入场与指示器。

| 场景 | 规则 |
| --- | --- |
| 视图切换 | 启动屏/登录/主界面以 fade+上移 10px 入场（320ms）；登录面板带 50ms 延迟与 spring。 |
| 列表 | 种子行使用 `TransitionGroup`：进场 fade+上移、离场快速淡出、排序/筛选变化走 FLIP 平滑移动（320ms）。 |
| 指示器 | 工作区导航选中态为白色胶囊滑动指示器（transform+width 过渡），按钮本身不再携带背景。 |
| 模态 | 桌面模态 fade+缩放(0.97→1)+上移入场，抽屉从右侧滑入；移动端沿用 `mobile-navigation.css` 的 surface 动画。 |
| 数据 | 概览指标数字滚动（320ms easeOut），进度条宽度线性过渡(400ms)，状态胶囊颜色过渡；轮询高频更新不逐帧动画，仅状态变化触发。 |
| 微交互 | 按钮按下 scale(0.96)，hover 背景/边框 200ms 过渡；不使用无边界的闪烁。 |
| 骨架屏 | 加载骨架为扫光渐变（shimmer 1.4s 循环）。 |
| 约束 | 只用 transform/opacity（进度条 width 例外）；`prefers-reduced-motion: reduce` 时全局动画/过渡近零并直接切换数值；触控 44px 与响应式布局不受动画影响。 |

组件色彩和表面样式集中在 `frontend/src/styles/components.css`。布局及导航几何保留在原样式表中，避免视觉微调改变响应式行为。

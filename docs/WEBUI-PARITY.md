# qBittorrent 5.x WebUI 功能对照

适配目标为 5.0+。字段清单来自官方 5.0 与后续 5.x WebUI 源码；界面以当前实例返回的字段为准。后续新增字段自动进入“其他设置”，保留原值类型。

| 原生功能 | OrbitDown 入口 |
| --- | --- |
| 行为、下载、连接、速度、BitTorrent、RSS、WebUI、高级设置 | 完整设置；名称/字段搜索、分组、差异保存、撤销 |
| 密码与私钥 | 服务端掩码；留空保留，明确勾选后清除；WebUI 密码只可替换 |
| 网络接口、绑定 IP、监控文件夹 | 完整设置中的选择器和目录映射编辑器 |
| 正常/备用速度与定时计划 | 设置 → 速度；底栏切换备用限速 |
| 磁力、HTTP(S)、种子上传 | 添加下载；高级选项配置管理模式、布局、队列、限速、分享限制 |
| 启停、强制启动、校验、重新汇报、队列优先级 | 任务行 / 详情 / 多选工具栏 → ⋯ 操作菜单 |
| 自动管理、顺序/首尾优先、超级做种、分类/标签、路径、分享限制、导出种子 | ⋯ 操作菜单 |
| 文件优先级、文件与文件夹重命名 | 详情 → 文件 / 高级操作 |
| Tracker 编辑、Peer 添加/封禁、分块、Web seeds | 详情 → 高级操作 |
| RSS 订阅、文件夹、文章、读取/移动、规则与匹配预览 | RSS 订阅；规则含原生下载参数 |
| 搜索任务、结果下载、分页、停止/删除、插件安装/启用/卸载/更新 | 种子搜索 |
| 分类/标签管理、运行/连接日志、统计、版本、关闭服务 | 管理工具 |
| 原生账号认证 | OIDC 网关认证；qBittorrent 服务账号仅保存在后端 |
| 连接 qBittorrent | OIDC 登录后点击左上角连接状态；填写 WebUI 地址和账号，测试并保存；服务端持久化，支持首次未配置启动 |

## 兼容行为

- 原生未返回的普通设置不会出现，不向实例盲写默认值。原生只写的 WebUI 密码提供替换控件。
- 原生已返回的新增设置保持可编辑；已知只读字段保留只读。WebUI API 密钥等秘密不返回浏览器。
- WebUI 地址、端口、HTTPS、认证和外部程序配置需在界面确认。服务账号修改会更新连接凭据并保存到服务端数据目录，重启后继续使用。
- 依赖 qBittorrent 编译选项或插件的功能，以实例响应为准；上游不支持时显示错误，不伪造成功。
- 单次添加请求最大 32 MiB，上传文件合计最多 31 MiB。演示只在开发服务器显式 `?demo=1` 时启用。
- 演示数据与真实服务隔离，不发送邮件或关闭服务；RSS 正则语法最终由真实 qBittorrent 的 PCRE2 引擎解释。

## 验证边界

本机模拟服务覆盖 API 验证、OIDC/CSRF、凭据隔离、设置读写、秘密掩码、负数范围与二进制导出。实际 qBittorrent/OIDC 端到端联调仍需目标实例配置。浏览器验证记录见 [VALIDATION.md](VALIDATION.md)。


## 交互补充

任务操作为紧凑非模态菜单：命令直接执行，限速、分享、分类、标签、路径与名称打开对应的小表单；不在任务列表中插入全量表单。顶部工具栏删除重复大标题，五个入口均有图标，手机以五等分展示。

移动端底栏为悬浮胶囊，保留安全区间距，包含玻璃材质、选中/按压反馈与进出过渡；减少动态效果/透明度时自动回退。样式参考 Apple 当前 [Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[Tab bars](https://developer.apple.com/design/human-interface-guidelines/tab-bars) 和 [Motion](https://developer.apple.com/design/human-interface-guidelines/motion) 指引，使用 Web 实现。

全站选择器采用可键盘操作的胶囊下拉；手机详情页签换行展示。主页、登录页与认证错误页使用共享 SVG 轨道和 CSS 渐变背景，固定覆盖视口，不依赖背景位图的尺寸。
